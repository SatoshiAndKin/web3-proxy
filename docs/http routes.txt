GET /
    Upgrades to a public WebSocket JSON-RPC connection.
    Redirects to redirect_public_url when the request is not a WebSocket upgrade.

POST /
    Proxies a public JSON-RPC request to the best available backend.

GET /fastest
    Upgrades to a public WebSocket connection that uses the fastest response mode.

POST /fastest
    Proxies a public JSON-RPC request and returns the fastest successful response.

GET /versus
    Upgrades to a public WebSocket connection for backend performance comparisons.

POST /versus
    Proxies a public JSON-RPC request to all eligible backends for comparison.

GET /health
    Returns 200 with "OK" when backend servers are synchronized.
    Returns 502 when no backend servers are synchronized.

GET /status
    Returns current proxy and backend status information.

GET /status/backups_needed
    Reports whether the proxy needs backup backends.

GET /status/debug_request
    Returns request metadata used for connection troubleshooting.
